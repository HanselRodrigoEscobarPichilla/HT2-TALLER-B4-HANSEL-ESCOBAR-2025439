El siguiente proyecto es una pequeña pagina web con la función de registrar nuevos productos. Con
mensajes de error personalizados con lo serian de caracteres mínimos o máximos, como lo podrian ser
los errores de campos necesarios o de cantidades negativas. Además cuenta con una pequeña ventana que
muestra el estado del formulario lo que muestra si es valido o invalido, si el botón fue tocado o no
y si fue modificado.
